# Social Downloader

Aplicación Android nativa con interfaz Glassmorphism.

## Versión 1.0
- Interfaz inicial en Jetpack Compose.
- Pegado de enlaces.
- Descarga de enlaces directos a archivos MP4, M4V, WEBM y MOV.
- Compilación automática mediante GitHub Actions.

Los enlaces de páginas sociales necesitan adaptadores específicos y disponibilidad permitida por cada plataforma. Esta versión no elude DRM, autenticación ni restricciones de acceso.

## APK
Abre la pestaña Actions, ejecuta **Build Social Downloader APK** y descarga el artefacto **Social-Downloader-debug**.
